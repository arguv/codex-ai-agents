
# Codex AI Agents Project

## Project Purpose

This repository is used to learn and practice specialized
Codex coding agents, agent orchestration, and reusable skills.

## General Instructions

- Read the relevant project files before making changes.
- Follow clean code principles.
- Prefer simple, maintainable solutions.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Explain important architectural decisions.
- Never expose or commit secrets.

## Development Workflow

1. Understand the requested task.
2. Inspect the relevant project files.
3. Create a plan when the task is complex.
4. Implement the requested changes.
5. Run relevant tests and checks.
6. Review the result.
7. Summarize what changed and any remaining issues.

## Agent Collaboration

This project will introduce specialized agents:

- Planner: analyzes requirements and prepares plans.
- Developer: implements approved changes.
- Tester: verifies behavior and reports failures.
- Reviewer: reviews correctness, security, and maintainability.

Use specialized agents when they are configured and useful
for the task. Do not delegate trivial work unnecessarily.

## Completion Requirements

For code changes, report:
- Files changed
- Main implementation decisions
- Tests executed and results
- Any remaining limitations
